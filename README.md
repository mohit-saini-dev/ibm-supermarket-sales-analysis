An end-to-end exploratory data analysis (EDA) and predictive modeling project developed as part of the **AICTE – IBM SkillsBuild Internship in Data Analytics with AI**. This project analyzes historical supermarket sales across multiple branches to uncover customer purchasing patterns, evaluate branch performance, and build predictive regression models for sales forecasting.

---

## 📌 Executive Summary & Key Highlights
* **Exploratory Data Analysis (EDA):** Identified revenue drivers across product lines, branch performance metrics, and peak transaction hours.
* **Customer Segmentation:** Analyzed purchasing behaviors across payment channels, membership types (Member vs. Normal), and customer ratings.
* **Predictive Modeling:** Implemented machine learning regression models using Scikit-Learn to estimate total purchase amounts based on transaction features.
* **Comprehensive Documentation:** Full analytical insights and visualizations documented in the [Project Report](docs/project_report.pdf).

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python 3
* **Data Processing & Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning & Modeling:** Scikit-Learn

## 📊 Key Findings & Business Insights

* **Branch Performance:** Consistent distribution of sales across branches with distinct product line preferences.
* **Top Revenue Drivers:** Food and beverage alongside electronic accessories generated higher total margin contributions.
* **Payment Trends:** Cash, Credit Card, and E-wallet adoption displayed balanced utilization, highlighting the necessity of multi-channel billing support.
* **Peak Shopping Hours:** Sales activity surged during late afternoon and early evening windows.

## 🚀 Getting Started & How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/mohit-saini-dev/ibm-supermarket-sales-analysis.git
cd ibm-supermarket-sales-analysis

```

### 2. Set Up a Virtual Environment (Optional but Recommended)

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

```

### 3. Install Dependencies

```bash
pip install -r requirements.txt

```

### 4. Launch the Notebook

```bash
jupyter notebook notebooks/supermarket_sales_analysis.ipynb

```
