# AICTE - IBM SkillsBuild Data Analytics with AI: Supermarket Sales Analysis

## Project Overview
This project performs end-to-end Exploratory Data Analysis (EDA) and predictive modeling on Supermarket retail sales data to forecast purchase totals.

## Tech Stack
* Language: Python 3
* Libraries: Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn

## How to Run
```bash
pip install -r requirements.txt
jupyter notebook Mohit_SupermarketSalesAnalysis.ipynb
```
